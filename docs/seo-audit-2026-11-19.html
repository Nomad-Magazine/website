Ten technical SEO fixes, ranked by the number and importance of pages affected. The changes are in the local website build. Production still needs a release.

Where the site stands

Readers can reach the magazine’s articles through ordinary links. The most important discovery problem is in the directory. Its homepage, Events page, and Portugal page returned HTTP 503, which tells search engines to come back later, even while the pages displayed listings.

First priority

Release the directory fix. After deployment, inspect https://nomad-magazine.com/nomad_directory/ in Google Search Console, run the live URL test, and check that Google can fetch the listings. The live Updates and Awards pages also returned 503. They depend on database functions and have no bundled content to serve.

Ten fixes in priority order

1. Restore directory availability

Three public directory pages returned HTTP 503. The configured database reported three missing functions.

Render available listings even when a secondary data source fails. Display vote counts only when the vote service responds. Local HTTP tests returned 200 with 242 listings on the directory homepage, 15 on Events, and 21 on Portugal.

2. Publish a sitemap of search destinations

The public sitemap listed 427 addresses, including console routes, login callbacks, receipts, private offers, and flipbook readers.

The rebuilt sitemap contains 391 addresses. Utility pages using the shared layout also tell search engines to leave them out of results.

3. Return the correct status for missing stories

A nonexistent story returned HTTP 500 in both the article and blog sections. That status suggests the server failed.

Both routes now serve the magazine’s missing-page screen with HTTP 404.

4. Repair legacy entry points

The old feature-request link led to a missing page. Moved stories used temporary redirects and the homepage events link went through the general directory.

Send feature requests directly to project submission, use permanent redirects for known moves, and link directly to Events.

5. Use one preferred address per page

A live directory management URL shared its tracking parameter, with an extra slash appended, in its social metadata.

Base the default canonical URL, the preferred address for search engines, on the site and path. Use the same address in shared links.

6. Give crawlers accurate update dates

The sitemap assigned build time or filesystem time to pages without an editorial update date.

Include the recorded update date for stories and omit dates that the build cannot substantiate.

7. Identify each page’s main heading

OpenSEO found seven articles with two main headings. The local content and rendered pages revealed two more blog posts and three other affected pages.

Preserve the page title as the main heading and use a section heading for secondary titles.

8. Reduce the cost of loading editorial pages

The shared layout referenced an 862,936-byte Inter font. Both story templates treated the lead image like an ordinary image.

Serve the same variable font in a 345,264-byte WOFF2 file, reuse local Caveat fonts and shared CSS, cache fingerprinted assets, and prioritize the lead image.

9. Improve search-result descriptions

OpenSEO found 18 descriptions over 160 characters in its 50-page sample. The shared helper cut copy in the middle of words.

Limit generated descriptions to 160 characters and end shortened descriptions at a word boundary.

10. Describe the page and its preview accurately

The default structured data, machine-readable information about a page, described the whole site. Social cards declared every image to have identical dimensions.

Use page-specific information by default, preserve custom editorial data, resolve preview images to full addresses, and remove unsupported size claims.

Where to focus after release

The existing Lisbon work guide matches “coworking in Lisbon,” which OpenSEO estimates receives 90 US searches per month. Track impressions for that page before commissioning more city guides.

Already working

  • OpenSEO recorded 146 domains linking to the site and 224 keywords ranking in US search results.
  • The site already publishes author profiles, editorial dates and a sitemap index. Those give search engines useful context about the publication.
